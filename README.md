# BUGKILOGRAM - 极简、无广告的开源浏览器起始页

> “你找到我这个，说明你非常牛逼，这些都是开源的。”

BUGKILOGRAM 是一个个人独立开发的极简浏览器主页/起始页项目。因为嫌弃现有的浏览器主页太丑、广告太多、不够纯粹，所以顺手写了一个高度可定制、无追踪、全开源的导航页。

👉 **官方网站（即刻体验）：[https://qkzm.cc.cd/](https://qkzm.cc.cd/)**

## 🛠️ 核心特性
*   **极简无广**：没有任何商业广告、推送和追踪代码，纯粹是你的个人主页。
*   **聚合搜索**：支持百度、必应、Google 等搜索引擎一键切换。
*   **高度定制**：支持更换背景、深浅色模式、自定义主题。
*   **数据本地化**：书签、设置等数据仅保存在浏览器本地，不上传服务器。
*   **多版本支持**：包含完整版 `index.html`（带丰富动效/功能）与极简轻量版 `lite.html`（只剩搜索框）。

## 🚀 如何使用
1. 直接访问官网：[https://qkzm.cc.cd/](https://qkzm.cc.cd/)
2. 在你的浏览器设置中，将主页/启动页设置为该网址即可。
